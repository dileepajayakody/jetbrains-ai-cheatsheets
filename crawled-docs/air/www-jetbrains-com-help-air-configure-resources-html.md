# Configure resources

Last modified: 21 May 2026

Custom resource configuration is not available yet.

At the moment, cloud environments use predefined VM sizes that you can select in the environment configuration. In a future release, you will be able to define your own VM sizes.

The following predefined VM sizes are currently available:

-   **Small** – 2 CPUs / 8 GB RAM / 20 GB disk space

-   **Medium** – 4 CPUs / 16 GB RAM / 30 GB disk space

-   **Large** – 8 CPUs / 32 GB RAM / 50 GB disk space

-   **Extra Large** – 16 CPUs / 64 GB RAM / 100 GB disk space
