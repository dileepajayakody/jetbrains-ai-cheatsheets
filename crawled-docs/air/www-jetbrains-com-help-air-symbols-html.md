# Symbols

Last modified: 25 February 2026

Use Symbols to browse symbols in the current file and navigate to their definitions. Symbols can include types, fields, functions, and methods. When you select a symbol, JetBrains Air opens the related code location in the editor.

### Open the Symbols tool

-   Navigate to View | Tools in the main menu and select Symbols.

-   On the tool panel, click Symbols.

### Navigate to a symbol

1.  In the Symbols tool, expand the symbol group.

2.  Select the symbol you need. JetBrains Air opens the symbol definition in the editor.
