# Changes

Last modified: 17 August 2026

Use Changes to review files that changed in the current workspace and to decide what goes into the next commit. Each row carries the file's added and deleted line counts, and the counter at the top of the list shows how many of the changed files you selected, for example 3/7 files.

### Open the Changes tool

-   Navigate to View | Tools in the main menu and select Changes.

-   On the tool panel, click Changes.

### View a file diff

1.  In the Changes tool, select a file from the changed files list.

2.  Review the diff in the Task Changes editor tab. For what you can do with the diff, see [Review changes](review-changes.html).

## What you can do here

-   [Commit changes](git-commit-and-push-changes.html#commit-changes-locally) by selecting the files you want to include and entering a message, or [amend the latest commit](git-commit-and-push-changes.html#amend-git-commits).

-   [Revert changes](git-undo-changes.html#revert_changes) in one file or in every file in the list.
