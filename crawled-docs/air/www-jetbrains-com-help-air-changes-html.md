# Changes

Last modified: 17 June 2026

Use Changes to review files that changed in the current workspace. You can see the list of changed files, open a diff for a file, and select what to include in a commit. You can also write a message and commit the selected changes.

### Open the Changes tool

-   Navigate to View | Tools in the main menu and select Changes.

-   On the tool panel, click Changes.

### View a file diff

1.  In the Changes tool, select a file from the changed files list.

2.  Review the diff in the Task Changes editor tab.

### Select files to commit

-   In the Changes tool, select the checkboxes next to the files you want to include.

### Commit changes

1.  In the commit message field, type a message.

    To have JetBrains Air draft the message for you, click Generate Commit Message ![Generate commit message](https://resources.jetbrains.com/help/img/air/generate-commit-message-icon.png "Generate commit message") next to Commit. Review and edit the suggested message before you commit.

2.  Click Commit.
