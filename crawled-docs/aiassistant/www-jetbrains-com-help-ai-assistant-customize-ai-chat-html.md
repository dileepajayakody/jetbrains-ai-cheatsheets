# Customize AI Chat

Last modified: 03 August 2026

You can customize how AI Chat behaves and looks.

## Open a chat in the editor

By default, chats are open in the AI Chat tool window, but you can also open a chat as an editor tab, which gives the conversation more space and lets you keep several chats open next to your code. To do this, click the Show Chats in Editor Tabs button.

![Open chat in the editor](https://resources.jetbrains.com/help/img/idea/2026.2/ai_open_chat_in_editor.png "Open chat in the editor")

As a result, the chat is opened in the editor tab, and the AI Chat tool window starts to display the chat history instead.

[![Ai chat in editor tab](https://resources.jetbrains.com/help/img/idea/2026.2/ai_chat_in_editor_tab.png "Ai chat in editor tab")](https://resources.jetbrains.com/help/img/idea/2026.2/ai_chat_in_editor_tab.png)

## Change the chat response language

You can instruct AI Assistant to provide responses in a specific language.

1.  Press CtrlAlt0S to open settings and then select Tools | AI Assistant.

2.  In the Natural Language section, enable the Receive AI Assistant chat responses in a custom language setting.

3.  In the text field, specify the language in which you want to receive chat responses.

    ![Specify chat response language](https://resources.jetbrains.com/help/img/idea/2026.2/ai_specify_chat_response_language.png "Specify chat response language")

4.  Click Apply.

After that, AI Assistant will use the specified language in its responses.

> ### note
>
> Enabling this feature updates the active chat to use the selected language. New chats will also use the selected language; however, existing ones will remain in a language that was selected previously.
