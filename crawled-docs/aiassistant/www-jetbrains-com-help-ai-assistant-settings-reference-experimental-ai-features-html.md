# AI Assistant Experimental Features

Last modified: 04 March 2026

Settings | Tools | AI Assistant Experimental Features

Use this page to manage [Overview and setup](experimental-ai-features.html) features in AI Assistant.

![AI Workflows settings](https://resources.jetbrains.com/help/img/idea/2026.1/ai_settings_reference_ai_workflows.png "AI Workflows settings")

Item

Description

Enable AI Assistant Experimental Features

Select this setting to enable experimental AI features.

## Recap

Item

Description

Enable Recap

Select this setting to enable the use of the Recap feature.

Auto-Update

Select this setting to automatically update the Recap when no activity is detected for a specified period of time.

Update Recap after

Specify the period of time after which the Recap must be automatically updated.

For additional information, refer to [Recap](recap.html).

## Insights

Item

Description

Enable Insights

Select this setting to enable the use of the Insights feature. After that, the Insights will start to appear for complex code in the editor.

Insights frequency

Specify how often you want to receive insights. Possible options:

-   Show more insights

-   Show fewer insights

For additional information, refer to [Insights](insights.html).

Description
