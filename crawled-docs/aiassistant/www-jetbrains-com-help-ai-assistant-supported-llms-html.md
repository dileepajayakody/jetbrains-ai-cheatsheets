# Supported models

Last modified: 22 May 2026

AI Assistant uses a variety of AI models to power its features and AI Chat. By default, these models are provided through the [JetBrains AI service](licensing-and-subscriptions.html), but you can also use models from supported third-party providers with your own [API key](/help/ai-assistant/supported-llms.html#models-from-third-party-providers) or connect [locally hosted](/help/ai-assistant/supported-llms.html#local-models) models.

This flexibility lets you choose the setup that best fits your workflow and privacy requirements.

## Models from third-party AI providers

AI Assistant supports the Bring Your Own Key (BYOK) approach, which lets you use your own API key to access models from supported third-party AI providers. With BYOK, you can use supported AI Assistant functionality without a JetBrains AI service subscription.

You can [configure](use-custom-models.html#provide-your-own-api-key) the connection in Settings | Tools | AI Assistant | Providers & API keys.

![Provide an API key](https://resources.jetbrains.com/help/img/idea/2026.1/ai_configure_third_party_providers.png "Provide an API key")

> ### note
>
> Not all features may be available when using models from third-party providers. For more information, refer to [Assign models to AI Assistant features](use-custom-models.html#use-custom-models-in-ai-features).

## Local models

Running models locally can be useful if you prefer to keep your data on your machine or want to experiment with locally hosted models.

AI Assistant supports a selection of models that can run locally on your machine through [Ollama](https://ollama.com/) and [LM Studio](https://lmstudio.ai/). This allows you to use AI-powered features without relying on cloud-based services.

You can [configure](use-custom-models.html#connect-local-models) the connection in Settings | Tools | AI Assistant | Providers & API keys.

![Configure local models](https://resources.jetbrains.com/help/img/idea/2026.1/ai_enable_third_party_providers.png "Configure local models")

> ### tip
>
> For more information about setting up local models, refer to [Connect local models](use-custom-models.html#connect-local-models).
