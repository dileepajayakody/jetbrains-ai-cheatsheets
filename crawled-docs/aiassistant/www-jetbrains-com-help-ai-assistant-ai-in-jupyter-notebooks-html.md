# AI Assistant in Jupyter notebooks

Last modified: 08 July 2026

**Only available in:** PyCharm Professional and DataSpell

Use Jupyter-specific AI features in PyCharm and DataSpell to [explain Jupyter cells and dataframes](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-explain-jupyter), [create new cells](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-create), [generate visualizations](/help/ai-assistant/ai-in-jupyter-notebooks.html#generate-visualizations), [edit cells](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-edit-cells), and [fix errors](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-fix-errors) in your code.

## Explain with AI

### Explain Jupyter cell

1.  Open a [Jupyter notebook](https://www.jetbrains.com/help/pycharm/jupyter-notebook-support.html) and do one of the following:

    -   Right-click the cell to open the context menu.

    -   Press ⌥ Option↩Enter.

2.  Select AI Actions and then Explain Code.

3.  Select Jupyter Cell or Whole Jupyter File.

    ![Explain Jupyter cell](https://resources.jetbrains.com/help/img/idea/2026.1/py_explain_cell.png "Explain Jupyter cell")

4.  The AI Assistant tool window will open to provide a detailed description of the Jupyter file or selected cell.

### Explain DataFrame

1.  Click !AI Actions in the upper-right corner of the output cell and select Explain DataFrame.

2.  The AI Assistant tool window will open to provide a detailed description of the dataframe.

## Create cells

### Create code cell from snippet

You can create a new code cell with AI-generated code in your [Jupyter notebook](https://www.jetbrains.com/help/pycharm/jupyter-notebook-support.html).

1.  Open or create an .ipynb file.

2.  Click Insert Snippet as Jupyter Cell in the upper-right corner of the field with the generated code.

    ![Create File from Snippet action](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_create_cell_from_snippet.png "Create File from Snippet action")

### Create AI cell

AI can create a new cell with AI-generated code based on your request.

1.  Click the AI button in between cells.

    ![Select AI from the button](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_create_cell.png "Select AI from the button")

2.  Type your request in the AI Assistant input field and click Send or use [AI suggestions](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-suggestions).

3.  AI Assistant will generate a code for the new cell:

    ![Accept the code suggestion](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_submitted_code.png "Accept the code suggestion")

4.  Select Accept and Run to add the code to the cell and run it as-is or Accept to add the code to the cell and continue working on it.

## Generate visualizations

AI Assistant can generate code snippets for data visualizations based on your dataframe.

1.  Do one of the following:

    -   Click ! AI Actions in the upper-right corner of the output cell and select Generate Visualizations in Chat.

        ![Generate visualizations](https://resources.jetbrains.com/help/img/idea/2026.1/py_generate_visualizations.png "Generate visualizations")

    -   Type `/plot` in AI Assistant chat and use `#` to mention the dataframe.

        ![Ask AI Assistant to generate visualizations in chat](https://resources.jetbrains.com/help/img/idea/2026.1/py_ask_ai.png "Ask AI Assistant to generate visualizations in chat")

2.  AI Assistant will suggest AI-generated code snippets for several visualizations.

    ![Visualization code snippets generated by AI Assistant](https://resources.jetbrains.com/help/img/idea/2026.1/py_ds_suggest_visualizations_window.png "Visualization code snippets generated by AI Assistant")

3.  Select one of the following options:

    -   Copy the suggested code to the clipboard.

    -   Insert code into the editor at the caret position.

    -   Create a new code cell from the snippet.

> ### tip
>
> You can specify the requirements for the visualization in chat, and AI Assistant will generate the code snippet for you.
>
> For example, if you type `/plot #jupyter:df histogram of x column with legend and values`, AI Assistant will suggest a relevant code snippet.

## Edit cells

AI Assistant can help you modify existing cells.

1.  Place the caret anywhere in the cell you want to edit and press ⌘Cmd0\\.

    Alternatively, right-click the cell and select AI Edit Cell from the context menu.

    ![Select AI Edit Cell](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_edit_cell.png "Select AI Edit Cell")

2.  Type your request in the AI Assistant input field and click Send or use [AI suggestions](/help/ai-assistant/ai-in-jupyter-notebooks.html#ai-suggestions).

3.  AI Assistant will generate new code.

4.  Select Accept and Run to add the code to the cell and run it as-is or Accept to add the code to the cell and continue working on it.

### Use AI suggestions

AI Assistant can analyze your notebook data and offer you a choice of prompts for code suggestions.

1.  Click the ![Suggestions](https://resources.jetbrains.com/help/img/idea/2026.1/app-client.expui.codeInsight.intentionBulb.svg "Suggestions") Suggestions icon on the right side of an AI input field.

2.  Choose one of the suggested prompts. The selected prompt, combined with notebook data sent for analysis, will be used for code generation.

    ![Prompts suggested by AI](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_suggested_prompts.png "Prompts suggested by AI")

## Fix errors

When your notebook or cell execution fails with an error, the AI Fix Cell option appears in the context menu.

1.  Right-click the cell you want to fix.

2.  Select AI Fix Cell from the context menu.

    ![Select Fix Cell from the context menu](https://resources.jetbrains.com/help/img/idea/2026.1/py_ai_fix_cell.png "Select Fix Cell from the context menu")

3.  AI Assistant will generate new code with the error fixed.

4.  Select Accept and Run to add the code to the cell and run it as-is or Accept to add the code to the cell and continue working on it.
