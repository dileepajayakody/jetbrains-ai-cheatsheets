# JetBrains AI Assistant — Editorial Seed

Voice: practical, IDE-native, productivity-focused. AI Assistant lives **inside
JetBrains IDEs** — chat, code completion, and code-aware help woven into the
editor. Distinguish it from Junie (the autonomous agent): AI Assistant augments
the developer in the loop; Junie executes delegated tasks.

## Sections to cover (roughly)

1. **Getting Started** (s1, ⚡) — what it is, IDEs supported, how to enable, JetBrains AI subscription.
2. **AI Chat** (s3, 💬) — the chat tool window, attaching context (files, symbols, commits), follow-ups.
3. **Code Completion** (s2, ⌨️) — multiline/whole-line completion, accepting/cycling suggestions.
4. **In-Editor Actions** (s5, ✏️) — explain code, generate docs, write tests, suggest refactorings, commit messages.
5. **Models & Providers** (s8, 🧠) — JetBrains AI models, provider/local model options, BYOK.
6. **Context & Attachments** (s6, 🧭) — how to give the assistant the right context; project awareness.
7. **MCP & Tools** (s7, 🔌) — connecting external tools/data; settings path; approvals.
8. **Prompts & Custom Commands** (s9, 🤖) — saved prompts, prompt library, custom instructions.
9. **Privacy & Controls** (s12, 🔒) — data handling, what's sent, enterprise controls, disabling features.
10. **Shortcuts** (s4, ⚡), **Pro Tips** (s3, 💡) — keyboard entry points and demo-worthy habits.

## Pro tips flavor
Attach precise context for better answers; use in-editor actions over copy-paste;
pick the model that fits the task; keep sensitive code in mind with provider choice.

## Note
Use the official docs as source of truth — feature names and availability are
version-sensitive. End with an "Updated" row noting the docs scrape date.
