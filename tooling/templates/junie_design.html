The agent loop
PatternPrompt → plan → edits → commands → verify → summary
Good taskBounded, testable, reviewable engineering outcome
ExamplesAdd tests, fix failures, map architecture, update README
ProgressJunie reports steps during multi-step work
VerifyTests, inspections, builds, and command output
ReviewKeep or roll back the agent's changes
IterateFollow up with narrower prompts from current state

/plan <prompt>Toggle plan mode; submits prompt if given
/modelPick the main LLM (Default auto-selects best value)
/accountManage accounts, API keys, and BYOK providers
/mcpConnect & manage MCP servers
/usageCost breakdown: tokens & models this session
/historyBrowse and resume previous sessions
/commandsCreate & manage custom slash commands
/extensions newSkills, MCP, subagents, commands as bundles

/install-github-actionWizard to set up the GitHub Action
/settingsTheme, notifications, step limit, diff view
/feedback <text>Send feedback (attaches session logs)
/update · /quitCheck for updates · exit (stay logged in)

Troubleshooting
Output driftsNarrow scope, attach fewer files, retry from state
Won't triggerCheck trigger phrase, labels & write permissions
Auth failsRe-check JUNIE_API_KEY / BYOK key in /account
CI skippedshould_skip = missing trigger or write access
Wrong modelAvailability is version-sensitive — set via /model
MCP blockedApprove the action or add it to the Allowlist
Stale CLIRun /update; confirm junie --version
Non-determinismExpect variation; verify before treating as final
